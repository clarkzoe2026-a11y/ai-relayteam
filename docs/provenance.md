# 来源与信任等级

| 标签 | 含义 | 用法 |
| --- | --- | --- |
| VERIFIED | 有可复查的技术证据，已实际核对 | 附命令、结果、文件或版本；写清验证范围 |
| USER_CONFIRMED | 用户明确拍板或人工验收 | 记决定与范围；不要改写成技术验证 |
| AGENT_REPORTED | AI 或执行者自述，负责人未独立核对 | 保留来源，等待复核 |
| UNKNOWN | 缺证据或未测试 | 写明待确认项，不推断为完成 |

例如：测试通过可标 VERIFIED；用户说视觉效果可以发布才标 USER_CONFIRMED；执行者说已修好先标 AGENT_REPORTED。技术检查不能替代人工验收。
