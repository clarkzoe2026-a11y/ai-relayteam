# Working on several projects

Each project has its own `AGENTS.md`, `HANDOFF.md`, `STATUS.md`, and session. Confirm the path before entering a directory, then read that project's rules. State the project and working directory in a dispatch; authorize and record cross-project work separately. Do not treat one project's authorization, identity allowlist, or progress as facts about another. With several workers, assign one writer per file; the lead checks each project's `git status` before combining results.
